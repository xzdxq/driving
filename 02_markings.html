标线、信号灯、手势：路上真正的指令

标线是画在地上的规则，比头顶的牌子更常被忽略：牌子你还抬头看一眼，地上的线很多人压根没看见。它们和信号灯、交警手势一起，决定你这一刻能不能动。

1标线的两个坐标：颜色 + 虚实

别一条条背线。先看颜色判断它管哪股车流，再看虚实判断能不能跨。两个坐标一组合，绝大多数标线当场就能读出来。

白色：管“同向”

分隔同向车流、划出车道边界、告诉你在路口该往哪走。白线两边跑的车，方向是一样的。

黄色：管“对向”和“路边”

画在路中间，分隔对向车流，等于一堵不能随便跨越的墙；画在路侧，管的是能不能停车。

为什么 白线像同一条流水线上的分隔栏，越过它只是换一条道；黄线像对面的墙，越过去就是迎着对向车流。虚实则是“这堵墙有没有开口”：虚线是留给你安全变道或借道的口子，实线是封死的。

七种中心线，一眼判定

白虚线同向车道的分界，安全时可以变道。
白实线车道边界，不得越线变道，也不得压线行驶。
双白实线隧道、桥梁、匝道等严禁跨越，两条线就是双重强调。
黄单实线分隔对向车流，禁止跨越、禁止压线。
黄双实线严禁跨越：不超车、不掉头、不压线。
黄虚线安全时可借道超车、掉头，对向有车就等。
黄虚实线虚线一侧可越，实线一侧不可越。只看你这一侧。
判定 白线管同向，黄线管对向；虚线是“可以，但要看安全”，实线是“不可以，没有例外”。黄虚实线只看自己这一侧：自己这边虚线就能越，实线就不能越。

路侧的黄线：管的是停车，不是行车

路侧黄实线 = 禁止停车一秒都不能停：上下客、等人、看导航都不行。
和红叉标志一一对应
路侧黄虚线 = 禁止长时停车可临时上下客，人不能离车，也不能停着不走。
和单斜杠标志一一对应
虚线是允许，实线是禁止，不是建议。
别搞混 实线不是“没车就能过”。只要车轮压上白实线或黄实线，就是违法；实线区唯一正确的操作是：提前在虚线区把车道选好。
上手 变道三件事：打灯 → 看镜和盲区 → 确认安全后一次跨过一条线。不要连续跨两条实线，也不要在实线区的最后几米硬挤。

2车道类标线：先选道，再进路口

路口最常见的违法不是闯红灯，而是到了实线区才发现走错道。车道标线的作用，就是让你在虚线区把“左、直、右”定下来，进了实线区就不再给你反悔的机会。

导向箭头 进路口前按箭头选道。已经进入实线区，就只能按箭头走，不能再变。
可变导向车道（锯齿线） 车道功能不固定。看上方电子屏或车道指示牌“此刻是什么”，别按昨天或印象走。
潮汐车道 双黄虚线 + 可变标志/车道灯。按当前指示方向走，逆着走就是逆行。
菱形标线 人行横道预告，看到就松电门、脚放刹车。减速丘和振荡标线则是在“强制”你慢下来。

左转待转区：直行绿灯先进，左转绿灯再走

这是新手最容易“不敢进”或“抢着进”的地方。规则其实很清楚：同方向直行绿灯亮时，左转车可以越过停止线、驶入待转区等待；左转绿灯亮时，再从待转区完成左转。左转和直行都是红灯时，必须停在停止线后方。

动画循环：车先越过停止线进入虚线待转区停住，等左转箭头变绿后才驶出。两个灯都红时，不许进。

看动画时只记一件事：进待转区看直行灯，出待转区看左转灯。左转灯红着就老实等，别把待转区当“提前转弯区”。

为什么 路口里的每一秒都有不同方向的车流在交叉。如果大家都在路口中间才决定“我要左转”，整个路口的放行节奏就会被打乱。标线用虚实把决策窗口前移：在直行段完成选择，进路口只负责执行。
直行待行区

给直行车的“提前排队区”，只在电子屏提示“直行车辆进入待行区”时才能进；没有提示就停在停止线后。

公交专用道

地面常写“公交专用”并标时段。时段内社会车辆不得占用；能不能借道右转，看现场标志，不靠猜。

非机动车道

和机动车道之间多为白实线。机动车不得驶入、不得借道超车，更不能停车占道。

判定 路口前 50–100 m 就把车道选好；进入实线区就不再变道。特殊车道的功能看当前电子屏/车道灯，不看记忆、不看导航的旧数据。
别搞混 锯齿线车道不是“固定左转道”。它的方向可能按早晚高峰切换，头顶写什么就走什么；排错队就按当前箭头走，到前面再绕，别在实线区硬挤。

3禁止压、禁止停的三种线

有三种标线，画的不是“路”，而是“别进来”：导流线把车流分开，网状线给路口留出泄洪口，停止线给红灯留出缓冲。压上去的那一刻，你不是在省时间，是在堵别人的路。

导流线 白色斜纹区域，不是“缓冲带”。不得压线、越线行驶，更不能停车。
停止线 红灯时必须停在停止线后方，车头不越线。越线就是违法，也容易挡住行人和横向车流。

网状线：堵车时更不能停上去

停在网状线前
前面堵着，就在网格线外等。等路口空出位置，再跟上去。
VS
停在网状线上
自己看着只是“跟着前车”，实际把横向车流整个堵死，路口越堵越死。
为什么 网状线画在路口内部或出入口，是给横向车流和转弯车流留的通道。它不要求你停，它要求你别停。所以判断标准不是“是不是绿灯”，而是“前面有没有空位容得下我的车”。
判定 导流线：不压、不越、不停。网状线：任何时候都不停，前方拥堵就在线外等。停止线：红灯车头不过线，黄灯未过线就停。
血亏操作 绿灯亮着，前车往前挪一点，你也跟着把车头顶进网状线，然后前车停住——整条横向车流被你堵死。正确做法：等前车完全通过、网格内腾出你车长的空间，再进。

4信号灯：先找“管你的那盏灯”

信号灯只做一件事：分配这一秒哪股车流先走。红灯 = 你这股车流没有通行权；绿灯 = 有；黄灯 = 马上收回，只给已经进路口的车收尾。所以看灯不是背口诀，而是走三步：我在哪条道、往哪走 → 哪个灯管这个方向 → 它现在什么颜色。

三步找灯，一步都别跳
  1. 先定位自己：我在左转道、直行道还是右转道，准备往哪个方向走。
  2. 再找管它的灯：看自己车道上方的箭头灯；没有箭头灯，才看圆饼灯。别盯着旁边车道或对向车道的灯。
  3. 最后看颜色：红灯停、绿灯行；黄灯看车头有没有越过停止线。

圆饼灯是总开关，箭头灯是分开关

圆饼红灯（总开关）
管整股车流：直行、左转必须停；右转有条件可走，见例 2。
VS
右转箭头红灯（分开关）
只对右转下命令。这时不管圆饼什么颜色，右转都得停在停止线后。

箭头灯亮着，听箭头的；箭头灭了，回到圆饼灯。“箭头没亮”不等于“箭头是绿的”。

为什么 右转一般不和对面直行车流正面冲突，所以法律留了一个“让行后可以走”的口子。但有些路口右转和行人、横向车流冲突大，就会加装右转箭头灯——箭头一亮红，就是这个方向现在真的不能走。

三个路上最常见的例子

例 1｜直行绿灯亮了，我要左转

直行绿灯只放行直行，左转箭头还是红的。如果路口画了左转待转区，可以把车开过停止线、进待转区等；没有待转区，就在停止线后等。等左转箭头变绿再转。

看到直行绿就一把方向转过去，属于不按信号灯通行（闯红灯），6 分。

例 2｜圆饼红灯，右转走不走？

三个条件同时满足才可以：① 没有“禁止右转”标志；② 不妨碍被放行的车辆和行人；③ 现场没有其他限制。满足就减速右转，缺一个就停在停止线后等。

  • 斑马线上没人、右侧横向也没车 → 可以转。
  • 有行人正走到你车头方向 → 停住等，不能边转边挤。
  • 路口有右转箭头，且箭头是红的 → 不能转，等箭头变绿。
例 3｜绿灯亮着，但路口堵死了

绿灯只说明“允许通行”，不说明“有地方停”。前方车已经排到路口中间，你开进去只会横在路口，等横向绿灯亮时把整条路堵死。正确做法：停在停止线外，等前面腾出能放下你整车的空位再走。路口堵塞时不得进入路口，这是硬规定。

黄灯亮起时，只看一件事：车头过线没有
  • 已经越过停止线：继续通过，别在路口中间急刹。
  • 还没越过：能平稳停住就停。例：车头离停止线还有 5 米，黄灯亮——踩刹车，别踩油门。
  • 黄灯一直闪：这不是红绿灯，是警示灯。减速、左右看，让右方来车，确认安全再通过。
  • 灯全灭或乱闪：当无信号路口处理——减速、让右方来车、转弯让直行；有交警就听交警。
黄灯不是“加速灯”，它只给已经进入路口的车留收尾时间。你踩得再深，它也不会变长。
判定 三步：定位车道 → 找管方向的灯 → 看颜色。有箭头灯按箭头，箭头不亮看圆饼；圆饼红灯右转 = 无禁令 + 让行 + 安全，三个条件缺一不可；黄灯看车头是否过线；路口堵了，绿灯也不进。
别搞混 一、圆饼红灯右转是“可以”，不是“应该”，后车按喇叭也不能抢。二、绿灯不是“免死金牌”：起步前还要扫一眼斑马线，防抢行的行人和电动车。

5交警手势：现场最高优先级

信号灯坏了、事故堵死、大雾看不清，交警就会站到路中间用手势接管路口。这时候他的手比灯大。你不需要背整套教材，先记住三个方向逻辑，再认识八种常见手势。

停止面向你，手臂高举。看到就停，别再往前挪。
直行手臂摆向你要去的方向，允许该方向车流通过。
左转弯摆臂指向左侧，允许左转。看懂方向，不要只盯手掌。
左转弯待转示意左转车先进入待转区等待，还不是让你立刻转。
右转弯摆臂指向右侧，允许右转。右转也要让行人。
变道手臂水平摆动，提示车辆按指示变道，不是催你快走。
减速慢行单臂前伸、向下压。脚离电门，把速度降下来。
靠边停车手臂指向路侧，打右灯、减速，靠边停稳。

以上是“手臂指向”示意图，不是完整动作分解；现场以交警的实际手势为准。看不懂时最安全的动作只有一个：先停住，别猜。

为什么 交警在现场，能看到你看不到的信息：前方事故、救护车要通过、信号灯故障、路口已经堵死。所以规则把现场指挥放在最高优先级，不是为了让人难记，而是为了让路口只有一个决策源。
记法 面向你 + 手臂高举 = 停止；手臂摆动指向哪边 = 允许往哪边走；单臂前伸下压 = 减速慢行。先看交警面向哪股车流，再看他的手臂，不要看他背对你时的动作。
现场听谁的？
交警手势＞ 信号灯＞ 交通标志＞ 交通标线

交警手势和信号灯冲突时，听交警；信号灯和标线冲突时，以信号灯为准；导航和现场冲突时，以现场为准。

别搞混 交警在指挥横向车流，不代表你也能走。他只对面向的那股车流发指令；你这条车道没收到放行信号，就继续停在停止线后。

6速查表：一张表收口

练车前扫一眼，路上只需要记住“颜色看方向，虚实看能不能越”。具体处罚和特殊路段规定，以现场标志和当地规定为准。
